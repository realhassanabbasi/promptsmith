      The rubric
      Five checks. No mystery score.
      Each dimension is visible, deterministic, and worth twenty points. PromptSmith tells you what failed and what to fix.
      
      
      01 / 20
      Clarity
      Starts with a direct action instead of burying the ask.
      02 / 20
      Context
      Includes enough background for a grounded response.
      03 / 20
      Specificity
      Uses concrete names, numbers, tools, or constraints.
      04 / 20
      Format
      Defines what the answer should look like.
      05 / 20
      Guardrails
      Sets tone, limits, and an honesty rule.
